快捷键（焦点不在输入框时生效）

空格 打时间模式：给当前目标小节打点并自动前进；其他模式：播放/暂停
Enter 同上（只在打时间模式打点）
Backspace 撤销上一步
[ ] 打点目标 −1 / +1 个小节
← → 后退 / 前进 2 秒（按住 Shift 为 5 秒）
K 播放 / 暂停   - = 减速 / 加速   0 速度归 1
H 或 Esc 开关本窗口

鼠标 / 触摸

标小节：点谱面加点 · 打时间：点圆点记时间（Shift+点 = 只把目标移过去，不记）
播放：点圆点跳到当前段落的那一遍；2 秒内再点同一个点就换到下一遍
编辑点：拖竖线中段挪位置，拖上/下端改长度，单击开面板（可设高度并应用到全部）

反复 / 练习

段落条自动从打点数据切出来（小节号往回跳 = 新的一遍），点一下跳到那一段；
播放时当前段落会自动高亮，所以点小节默认就落在你正在听的那一遍。
练习循环：按「起点」再在谱面点一个小节 = 循环起点，「终点」同理（那一小节会唱完），再按「循环」开关。

自动生成时间轴

只生成时间；小节在纸上的位置仍然要自己标。 手动卡的时间点会被当成硬锚点保留，生成的时间在锚点之间按比例拉伸对齐。

速度 （很少变，通常就一行）

拍号 （一个拍号一行，后面写它管哪些小节，写法同播放顺序：1, 3, 5-25, 27；留空的那行兜底管其余全部）

每小节实际拍号 （白框 = 被某一行明确指定，其余靠兜底行）

播放顺序 （留空 = 全曲从头到尾一遍）

锚点 （决定整条时间轴的绝对位置）

小节 = 秒

校准

MP3 是 MIDI 渲染的话，反推值多半接近某个整数，手动取整会更准
