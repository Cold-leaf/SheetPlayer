操作说明

手势（触摸屏）

双指缩放：两根手指捏合缩放谱面，以两指中点为锚点。
桌面等价物：Ctrl + 滚轮（触控板双指捏合同理），只缩放谱面、不缩放工具栏。
单指拖动谱面平移。拖动后自动跟随会暂停 2.5 秒，然后自己恢复—— 不是跟随失灵，是让手先看完这一页。
排练胶囊：点工具栏「▲」收起工具栏，底部出现一条胶囊 [⏮][▶][⏭] ──进度── 曲名 [倍速] [⌃]； 进度条按住可以拖动走带——触屏没有 ←/→ 键，这是唯一的精细定位手段； 两侧的 ⏮/⏭ 切曲目，「⌃」展开工具栏。
频谱打开后：拖空白 = 像拖胶片一样连续走带，单击 = 定位，拖竖线 = 微调那个时间点。 频谱头上的提示文字窄屏不显示，但手势一样管用。
编辑点模式下才能拖竖线：按住中段拖动挪位置，拖上/下端改长度； 这个模式下谱面不随手势滚动（免得拖动时页面乱跑），要先切回别的模式才能滚谱。

鼠标

标小节：点谱面加点 · 打时间：点圆点记时间（Shift+点 = 只把目标移过去，不记）
播放：点圆点跳到当前段落的那一遍；2 秒内再点同一个点就换到下一遍
编辑点：拖竖线中段挪位置，拖上/下端改长度，单击开面板（可设高度并应用到全部）

快捷键（焦点不在输入框时生效）

空格 打时间模式：给当前目标小节打点并自动前进；其他模式：播放/暂停
Enter 同上（只在打时间模式打点）
Backspace 撤销上一步
[ ] 打点目标 −1 / +1 个小节
← → 后退 / 前进 2 秒（按住 Shift 为 5 秒）
K 播放 / 暂停   - = 减速 / 加速   0 速度归 1
H 或 Esc 开关本窗口

反复 / 练习

段落条自动从打点数据切出来（小节号往回跳 = 新的一遍），点一下跳到那一段；
播放时当前段落会自动高亮，所以点小节默认就落在你正在听的那一遍。
练习循环：按「起点」再在谱面点一个小节 = 循环起点，「终点」同理（那一小节会唱完），再按「循环」开关。

关闭浮层

点浮层外面的灰底，或者右上角的 ✕ / 「关闭」键。帮助、生成、ownCloud、各种对话框都是这么关的 （平板上没有 Esc 键，这两条是唯一的出路）。

安装到主屏幕

装成 App 后有独立图标、全屏无地址栏、离线也能打开（谱子和音频本来就在本机）。
看起来你现在就是从装好的 App 打开的，那就不用再装一次了。

iPhone / iPad（Safari）

点底部的「分享」⬆︎ → 往下找到「添加到主屏幕」→ 命名 → 添加。

Android / 桌面（Chrome、Edge）

地址栏右侧的安装图标，或右上角 ⋮ →「安装应用」/「添加到主屏幕」。

桌面 Safari

菜单「文件」→「添加到程序坞」。
改过图标之后，要先把旧图标从主屏幕删掉、再重新添加一次—— 图标是安装那一刻抓取的，不会自己更新。
ownCloud 曲库
只读：只列目录和下载，不往服务器写任何东西。凭据只存在本机浏览器，不进代码仓库。
点文件名下载并导入；PDF 会新建/接回曲目，音频挂到当前打开的曲目上（先打开一首再下音频）。

自动生成时间轴

只生成时间；小节在纸上的位置仍然要自己标。 手动卡的时间点会被当成硬锚点保留，生成的时间在锚点之间按比例拉伸对齐。

速度 （很少变，通常就一行）

拍号 （一个拍号一行，后面写它管哪些小节，写法同播放顺序：1, 3, 5-25, 27；留空的那行兜底管其余全部）

每小节实际拍号 （白框 = 被某一行明确指定，其余靠兜底行）

播放顺序 （留空 = 全曲从头到尾一遍）

锚点 （决定整条时间轴的绝对位置）

小节 = 秒

校准

MP3 是 MIDI 渲染的话，反推值多半接近某个整数，手动取整会更准
