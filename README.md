# SheetPlayer

谱音同步打点播放器 —— 单 HTML 文件实现：在五线谱 PDF 上标记小节，按音频打时间点，播放时谱面跟随高亮滚动。

## 使用

直接双击打开 `player.html`（离线可用，无需安装、无需网络）：

1. 「PDF」选择五线谱 PDF，「音频」选择音频（MP3 等）。
2. 「标小节」模式：点谱面标记每个小节的位置。
3. 「打时间」模式：空格键给当前小节打时间点（或点竖线）。
4. 「播放」模式：谱面随播放高亮滚动。

其他能力：自动生成时间轴（按拍号/播放顺序）、小节线吸附、频谱与起音吸附、多小节休止、横向铺开、练习循环、触屏适配、双指/触控板缩放、JSON 导入导出、localStorage 自动存档。

## 开发

- 源码即 `player.html` 单文件（CSS + JS 内联）。
- 测试在 `tests/`：
  - `tests/t*.js`：纯逻辑测试，`node tests/t.js` 逐个跑。
  - `tests/pw_*.py`：Playwright 浏览器端到端测试，`python3 tests/pw_bar.py` 等。
- 测试里的 PDF/音频路径指向本机 `data/assets/`，换机器需改 `ROOT`。

## 数据说明

标注数据（小节竖线、时间点、拍号/速度表）默认存浏览器 localStorage，按 PDF 文件名分档；用「导出JSON」可备份/迁移。
